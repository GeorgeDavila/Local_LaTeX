# Local_LaTeX
Local lightweight LaTeX document editor based on [LaTeX.js](https://latex.js.org/) for LaTeX rendering. Electron app. 


## Windows

Once you've downloaded this repo and did `npm install` you can now run it locally without a exe by using the `local_LaTeX.bat` file. You can `right click > send to > desktop (create shortcut)` the `.bat` file to create a shortcut like any other app. Be sure not to remove the `.bat` file from this directory.
